# Foto's plaatsen

De site verwijst naar de foto's hieronder. Zolang een bestand ontbreekt, toont
de site een nette placeholder (streeppatroon met label) — de layout blijft heel.
Zet de echte `.jpeg`-bestanden met **exact deze namen** in deze map
(`public/assets/`) en ze vallen automatisch op hun plek.

Optimaliseer ze bij voorkeur eerst (WebP/AVIF, meerdere formaten). Camerabestanden
zijn groot; ~2000px brede JPEG's zijn ruim voldoende.

## In gebruik op de site

| Bestandsnaam | Waar | Beschrijving |
|---|---|---|
| `hens-call-harbor.jpeg` | Home — hero-achtergrond | Hens aan de telefoon bij de haven (breed, wordt licht verduisterd door overlay) |
| `hens-coffee.jpeg` | Home slot-CTA + Contact zijkolom | Hens met een kop koffie |
| `hens-arms-bench.jpeg` | Aanpak — manifest | Hens met armen over elkaar op een bankje (staand 4:5) |

| `hens-notebook-laughing.jpeg` | Verhaal — "Hoe ik werk" | Hens lachend met notitieboek |
| `hens-call-down.jpeg` | Verhaal — manifest | Hens aan de telefoon, blik omlaag (staand 4:5) |

| `favicon-32.png`, `favicon-64.png`, `favicon-180.png` | Browser-tab / touch-icon | Nu gegenereerde placeholders. Vervang door de echte favicons. |
